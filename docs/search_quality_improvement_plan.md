# 검색 품질 개선 계획

## 실패 사례 분석

### Case 1: q001 "민법 제750조가 뭐야?" (Recall@10 = 0%)

**문제**: 삭제된 조문(785조, 780조)이 상위 노출, 실제 750조는 검색 실패

**원인**:
1. 직접 조문 질문 패턴 미감지
2. 벡터 유사도 한계 - 삭제된 조문(짧은 내용)이 높은 유사도

**해결 방안**: 정규식으로 "○○법 제XX조" 패턴 감지 후 DB 직접 조회

---

### Case 2: q005 "월세 계약 중도 해지" (Recall@10 = 0%)

**문제**: DB에 주택임대차보호법 제6조 존재하나 검색 실패

**원인**:
1. **임베딩 방식의 제목 과의존**
   - 현재 임베딩: `법령: {law}, 조문: {article}, 제목: {title}, 내용: {content}`
   - 주택임대차보호법 제6조: 제목 "계약갱신 요구 등", 실제 내용에 "④ 임대차의 해지" 포함
   - 제목("갱신")과 질문("해지") 불일치로 검색 실패

2. **일상 용어 vs 법률 용어 갭**
   - 질문: "월세", "중도 해지", "보증금"
   - 법령: "차임", "계약의 갱신", "임대차"

**해결 방안**:
1. 임베딩 텍스트 구성 변경 - 내용 우선
   ```python
   # 개선안
   text = f"{article['content']}"  # 내용을 제일 앞에
   text += f" [법령: {article['law_name']}, 조문: {article['article']}, 제목: {article['title']}]"
   ```

2. api를 통해 법률 용어 일상용어 비교 db 추가 저장
   - api 제공 문서중 법률 용어와 일상 용어를 비교하는 문서가 존재
   - 적절한 검토를 통해서 사용자의 질문과 법률용어를 매칭할 수 있는 지 검토 후 db에 저장
   - 명확한 매칭이 가능하다면 sementic이 아닌 질문에서 추출한 키워드로 1:1매칭을 통해 시간 절약

### Case 3: q006 "교통사고로 다쳤을 때 보상" (Recall@10 = 0%)

**문제**: DB에 자동차손해배상 보장법 제3조 존재하나 검색 실패

**원인**: q005와 동일 (임베딩 제목 과의존 + 용어 갭)
- 질문: "교통사고", "보상", "다쳤을 때"
- 법령: "자동차 운행", "손해배상", "부상"

### Case 4: q009 "근로기준법 별표 1" (Recall@10 = 0%)

**문제**: 별표 데이터가 VectorDB에 없음

**원인**: Law.go.kr API가 별표의 내용을 제공하지 않으며 별도의 PDF 형식으로만 제공, 현재 수집 대상 아님

**해결 방안** (장기):
- cRAG 방식으로 웹 검색 활용
- 또는 주요 법령 별표 수동 수집

### Priority 1: 즉시 개선 가능

**1. 임베딩 방식 개선**

- VectorDB 재구축 필요

**2. 직접 조문 질문 감지**
```python
def detect_direct_article_query(query: str) -> Optional[Dict]:
    pattern = r'([가-힣]+(?:법|령))\s*제?\s*(\d+)\s*조'
    match = re.search(pattern, query)
    if match:
        return {"law": match.group(1), "article": match.group(2)}
    return None
```
