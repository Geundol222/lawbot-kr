## 질문별 상세 결과

### Q011: 5인 미만 사업장에서 해고 예고수당은 어떻게 되나요?

**정답**: ✅ 5인 미만 사업장이어도 해고 예고수당은 적용됨 (근로기준법 제26조는 제11조 적용범위 예외)

| 모드 | 응답시간 | 토큰 | API 호출 | 검색 문서 | 정확도 |
|------|---------|------|---------|----------|--------|
| Vanilla | 19.8초 | 1,526 | 2 | 5개 | ✅ **정답** |
| Current | 24.7초 | 2,212 | 3 | 5개 | ✅ **정답** |
| Self-RAG | 63.3초 | 2,412 | 8 | 20개 | ❌ **오답** |

**분석**:
- **Vanilla**: "5인 미만이어도 지급해야 함" - 제26조만 참조, 정답
- **Current**: "5인 미만이어도 지급해야 함, 제11조와 구별 필요" - 상세 설명, 정답
- **Self-RAG**: "5인 미만은 적용 안 됨" - **제11조 과신으로 오답**
  - 반복 3회 수행했지만 오히려 제11조(적용범위)에 집착하여 제26조(해고예고)가 예외임을 놓침
  - 63초나 걸렸지만 **완전히 틀린 답변**

## 결론 및 권장사항

### 최종 선택: **Current 모드** ✅

**이유**:
1. **유일하게 100% 정확도 달성** - 서비스 신뢰성 확보
2. **속도 22.5초** - 실시간 서비스 가능 (30초 이내)
3. **법률 도메인 특화 설계** - check_exceptions_needed가 "5인 미만", "적용범위" 같은 키워드 정확히 감지
4. **비용 효율적** - API 호출 3회로 Self-RAG 대비 40% 절감

### Self-RAG를 추천하지 않는 이유

**기술적 인사이트**:
```
Self-RAG 논문의 가정: "더 많은 검색 → 더 나은 답변"
법률 도메인 현실: "잘못된 조문에 집착 → 오히려 오답"

예시 (Q011):
  초기 검색: 제26조 (해고예고) 발견 ✅
  Self-RAG 평가: "제11조(적용범위)도 필요할 것 같음"
  추가 검색: 제11조 발견
  LLM 판단: "제11조에 5인 미만 제외라고 나와 있으니 해고예고수당 안 받음" ❌
  실제 정답: 제26조는 제11조의 예외 조항 → 5인 미만도 받음 ✅
```

**결론**:
- 법률은 "원칙-예외" 구조가 명확 → 휴리스틱 기반 접근이 더 안전
- LLM 기반 Self-RAG는 오픈 도메인(위키피디아)에서는 유용하지만
- 구조화된 전문 도메인(법률)에서는 **오히려 혼란 초래**
